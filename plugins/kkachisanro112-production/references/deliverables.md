# 노션에 붙여넣을 산출물

## 1. 아이템 선정 기록
`선정 아이템 / 핵심 질문 / 선정자·선정 시각 / 이번 회차 범위 / 지역 연결의 근거 / 제외할 곁가지 / 제작진 결정 상태`

## 2. 세 기자 공통 브리프
`30초 설명 / 확인된 사실과 타임라인 / 당사자별 주장 / 지역 연결 근거와 한계 / 쟁점과 반론 / 세 기자의 취재 질문 / 추가 확인 / 출처 URL·확인 시각`

## 3. 1차 검증표
`팩트 ID | 말할 내용 | 직접 출처 URL | 발표·확인 시각 | 확인 결과 | 표현 주의 | 담당`

## 4. 30분 대화 대본 초안
`예상 시간대 | MC 겸 기자 발언 | 기자 2 발언 | 기자 3 발언 | 즉흥 질문·전환 | 화면 자료 ID | 팩트 ID`

방송의 첫 강한 사건 → 첫 판단 → 그 판단을 흔드는 자료 → 지역 맥락을 포함한 해석과 반론 → 처음 사건으로 돌아오는 정리 순서를 따르되 정해진 목차를 강요하지 않는다. 세 기자의 실제 대화가 이어지게 작성한다.

## 5. 방송자료 목록
`자료 ID | 출처·직접 링크 | 발췌할 정확한 부분·시간대 | 사용 장면 | 확인 시점 | 권리 확인 | 가공 담당`

## 6. 2차 검증 및 제작진 인계
`대본 발언/화면 ID | 일치하는 팩트 ID | 최신 확인 결과 | 수정 문구 | 방송 직전 확인 담당 | 제작진 확정 여부`

모든 자료는 작성·확인 시각을 KST로 표시한다. `초안`, `제작진 검토`, `최종 확정` 상태를 구분한다.
