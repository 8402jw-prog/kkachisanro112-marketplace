# 한 이슈 제작

[편집 기준](../../references/editorial-standard.md)과 [산출물 양식](../../references/deliverables.md)을 읽는다.

1. 제작진이 노션에서 승인한 **한 이슈의 고유명사와 질문**을 고정한다. 사용자가 직접 아이템을 지정했으면 선정된 것으로 본다. 선정되지 않았으면 후보 제안까지만 한다.
2. 1차 조사: 강한 사건과 첫 판단, 그것을 흔드는 검증 가능한 사실, 진행 중인 변화, 당사자와 지역 연결, 반론·자료 한계를 확인한다. 직접 출처 URL과 발표·확인 시각을 기록한다. 기자 3명 모두를 위한 공통 브리프와 각자 파고들 질문을 만든다. 필요한 추가 취재와 확인 전 발언 금지 내용을 표시한다.
3. 대본 전 1차 검증: 핵심 팩트마다 ID, 원자료, 확인 결과(확인/조건부/미확인/반박), 최근 확인 시각을 적는다. 여론조사는 조사기관, 의뢰자, 기간, 대상, 표본, 방식, 오차 등을 원문 기준으로 점검한다. 핵심 출처를 확보하지 못하면 그 대목을 보류한다.
4. 30분 구성·대본: MC 겸 기자 1명, 기자 2명이 모두 사실·분석·질문을 나눈다. 오프닝 2분, 사실과 맥락 6분, 쟁점과 현장·지역 연결 10분, 반론·다른 해석 8분, 정리 4분은 시작안이며 자료에 맞게 조정한다. 완성된 구어체 발언을 쓰되 즉흥 토론의 여지와 넘김 멘트를 남긴다. 세 기자의 역할은 성별로 나누지 않는다. 지역 연결이 희박하면 억지로 10분을 채우지 말고 원래 이슈의 다른 쟁점을 다룬다. `[F01]` 같은 근거 ID를 내부용 대본에 연결한다.
5. 대본 중이나 이후에 방송자료 목록을 병행 작성한다. 사용 가능 후보 자료별 원본 링크, 발췌 구간 또는 정확한 짧은 인용, 사용할 장면, 확인 시점, 사용권·저작권 검토 담당을 표시한다. 원문을 보지 못한 발췌·인용은 만들지 않는다. 자료의 최종 가공은 제작진이 한다.
6. 대본 후 2차 검증: 발언·화면·숫자와 팩트 ID를 다시 대조하고 최신 변동, 단정적 예측, 반론 누락, 권리 문제를 확인한다. 방송 직전 변동 가능 항목과 확인 담당을 넘긴다.
7. 노션에 복사 가능한 초안을 제출한다. 노션 접근 권한이 있으면 제작진이 정한 페이지에 초안으로 기록하되 **선정·대본 최종 확정은 제작진에게 남긴다**. 제작진 수정 후 바뀐 사실도 재검증한다.

MP3 요약은 진행 방식의 참고자료일 뿐 발화자의 정확한 말투나 주장의 근거가 아니다. 근거가 모자라면 `보류 / 추가 취재`를 표시하고 추측 대사로 채우지 않는다.
