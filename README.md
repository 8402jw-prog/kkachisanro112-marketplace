# 까치산로112 제작 플러그인 시험판

첨부된 `1km-content-marketplace`의 취재, 두 단계 팩트체크, 강한 사건에서 시작해 처음 사건으로 돌아오는 이야기 설계를 바탕으로 재구성한 **별도 사본**입니다. 원본 파일은 바꾸지 않았습니다.

## 사용 순서

1. `kkachi-discover`: 뉴스와 자체 채널의 최근 7일 업로드를 함께 보고 방송 후보 3개를 제시합니다.
2. PD·AD가 결과를 노션에 올리고 제작진이 **이야기 하나**를 선정합니다.
3. `kkachi-produce`: 세 기자용 취재 브리프, 1차 검증, 30분 대화 초안, 방송자료 목록, 2차 검증을 작성합니다.
4. 제작진이 노션에서 수정·최종 확정하고 자료 가공과 방송 제작을 합니다.

예시 요청: `까치산로112 이번 주 아이템 후보 3개를 찾아줘.` / `리센느 이슈로 세 기자가 대화할 30분 대본 초안을 만들어줘.`

## 자체 채널 조회

YouTube Data API 키가 있으면 **로컬 환경변수** `YOUTUBE_API_KEY`에 넣고 다음을 실행합니다. 채널 두 곳을 조회하며 영상 업로드 시점은 실행 시각 기준 최근 7일, 조회수는 실행 시점 누적값입니다.

```bash
python3 plugins/kkachisanro112-production/scripts/youtube_rank.py
```

키가 없으면 `미연결` 상태가 출력됩니다. 3분 이하 영상은 쇼츠 **후보**입니다. API가 공개 영상의 화면비나 확정적인 쇼츠 여부를 제공하지 않아, 쇼츠 탭 또는 제작진 기록으로 형식을 최종 확인한 뒤 상위 3개를 확정하세요. 비공개·삭제·통계 미제공 영상은 결과에 나오지 않을 수 있습니다. 노션 자동 게시 기능은 포함되지 않습니다.

플러그인을 등록하려면 이 폴더를 GitHub 저장소에 올린 뒤 Codex의 플러그인 마켓플레이스에 해당 저장소를 추가하세요. 현 단계는 로컬 시험판이며 실제 키를 사용한 조회, 노션 게시, 배포는 아직 검증하지 않았습니다.
